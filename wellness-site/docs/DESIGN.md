# 웰니스 데이터 사이트 설계서

노트북 1대와 AI로 월 50만원 부수입을 목표로 하는 사이드 프로젝트. 초기 자본 0원, 사람 개입 최소화.

## 1. 핵심 전략

"AI가 쓴 건강 글"이 아니라 **"공공데이터로 만든 계산·비교 도구"**를 만든다.

- 가치의 원천은 **계속 갱신되는 실제 데이터**다. AI는 데이터를 해설하는 보조 역할만 한다.
- 건강 분야는 Google이 가장 엄격하게 보는 YMYL 분야이고, 식품 효능 표현은 식품표시광고법 규제 대상이다. 그래서 효능 주장은 하지 않고 "무엇이 더 많다/적다"는 사실만 다룬다.
- 페이지를 많이 찍어내기보다 의미 있는 페이지만 만든다. 예를 들어 비교 페이지는 같은 분류에서 열량이 가까운 식품끼리만 만든다(`pickComparisons`). 대량 생성 스팸 정책(Scaled content abuse)을 피하기 위해서다.

## 2. 수익 구조 (목표 월 50만원, 추정치)

| 수익원 | 가정 | 월 |
|---|---|---|
| 애드센스 | 월 10만 페이지뷰 × 1천 뷰당 약 2,000원 | 약 20만원 |
| 쿠팡 파트너스 | 매출 500만원 × 약 3% | 약 15만원 |
| 디지털 상품 (식단·운동 플래너) | 9,900원 × 15개 | 약 15만원 |

목표 도달까지 6~12개월을 예상한다. 3개월째에도 검색 노출이 거의 없으면 주제나 페이지 유형을 바꾼다.

## 3. 아키텍처

```
[GitHub Actions: 매일 03:00 KST, 무료, AI 없음]
  식약처 API 수집 → data/foods.json → 테스트·검증 → 데이터 커밋
  → Astro 정적 빌드 → 운영 검증(--production) → Cloudflare Pages 배포

[노트북 Claude Code: 주 1회, 사람 참여]
  npm run commentary   해설문 생성 (claude -p), 자동 검사, 실패 시 1회 재시도
  npm run review       사람이 승인(y)/삭제(n)
  git commit && push   → 다음 배포에 반영
```

- 숫자는 항상 코드가 데이터에서 직접 넣는다. AI가 쓴 해설문의 숫자는 원본 데이터와 대조해 통과한 것만 저장한다.
- 사람이 승인한(`reviewed: true`) 해설문만 사이트에 노출된다.
- 노트북이 꺼져 있어도 사이트는 매일 갱신된다.

## 4. 안전장치

| 위험 | 대응 | 위치 |
|---|---|---|
| AI가 숫자를 지어냄 | 해설문 숫자를 데이터와 대조 | `src/lib/compliance.mjs` `findUnknownNumbers` |
| 효능·질병 표현 (식품표시광고법, 의료법) | 금지 표현 목록 검사 | `BANNED_PHRASES` |
| API 필드 매핑 오류 | 열량 ≈ 4×탄수화물 + 4×단백질 + 9×지방 검사 | `energyLooksConsistent` |
| API 장애로 데이터가 사라짐 | 최소 건수 미만이면 저장 안 함 | `scripts/fetch-foods.mjs` |
| 샘플 데이터가 운영에 배포됨 | 샘플이면 noindex와 배너, `--production` 검증에서 배포 차단 | `Base.astro`, `validate.mjs` |
| 확인 안 된 MET 값 | `verified=false` 항목이 있으면 배포 차단 | `data/exercises.json` |
| 제휴 고지 누락 | 링크가 있으면 쿠팡 필수 문구를 자동 표시 | `Affiliate.astro` |
| 건강기능식품 광고 | 제휴 링크는 운동용품·주방 도구로 한정 | `src/config/affiliate.mjs` |

## 5. 페이지 유형

| 경로 | 내용 | 데이터 |
|---|---|---|
| `/foods/{id}/` | 식품 영양성분 | 식약처 식품영양성분DB |
| `/compare/{a}-vs-{b}/` | 두 식품 비교 | 같은 데이터 |
| `/exercise/{id}/` | 체중·시간별 소모 열량 | Compendium of Physical Activities MET 값 |
| `/tools/bmr/` | 기초대사량 계산기 (브라우저 안에서만 계산) | Mifflin-St Jeor 공식 |
| `/about/`, `/disclaimer/`, `/privacy/` | 애드센스 심사에 필요한 기본 페이지 | 직접 작성 |

## 7. 운영 시 주의

- **세금**: 사업자등록을 하지 않아도 수입은 매년 5월 종합소득세로 신고해야 한다. 쿠팡 파트너스는 3.3%를 미리 떼고 지급한다.
- **겸업**: 직장 취업규칙의 겸업 금지 조항은 사업자등록 여부와 상관없이 적용될 수 있다.
- **데이터 출처**: 공공데이터는 출처를 표시해야 한다. 다른 사이트 크롤링은 하지 않는다.
- **정책 변경**: 애드센스, 쿠팡, Google 검색 정책은 바뀐다. 분기마다 한 번 확인한다.
